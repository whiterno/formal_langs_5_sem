# Формальные языки

Проект на Python 3.10+. Реализация находится в `language/`, примеры и решения — в `homeworks/`.

## Домашние работы

- [Папка домашней работы 2+3](homeworks/hw2-3/) — [решение и схемы](homeworks/hw2-3/README.md)

## Как запустить домашнюю работу

Из корня проекта запустите все номера домашней работы 2+3:

```bash
bash run.sh homeworks/hw2-3
```

Или только номер 2а:

```bash
bash run.sh homeworks/hw2-3 task2/task2a.py
```

Для другого номера укажите путь к соответствующему файлу, например `task2/task2b.py`. При запуске всей папки выполняются файлы заданий вида `task2/task2a.py`, `task2/task2b.py` и т. п.

Первый аргумент — папка домашней работы, второй — путь к файлу внутри неё. Если файл не указан, запускается `main.py` из этой папки. `run.sh` создаёт `.venv` при первом запуске и настраивает импорт пакета `language`. Рабочая папка программы — указанная папка домашней работы.

## Интерфейс

- `Automaton.from_regex(regex, alphabet=None)` — строит автомат по регулярному выражению. `+` или `|` означает объединение, запись подряд — конкатенацию, `*` — повторение, скобки — группировку, `1` — пустое слово, `0` — пустой язык. Обратная косая черта экранирует следующий символ.
- `Automaton(alphabet, states, transitions, start_states, final_states)` — создаёт автомат вручную. Состояния и алфавит задаются множествами; `transitions` — словарь вида `{(состояние, символ): {состояния назначения}}`. Символ `None` обозначает ε-переход.
- `accepts(word)` проверяет слово; `add_transition(source, symbol, target)` добавляет переход.
- `determinize()`, `complete()`, `minimize()`, `minimize_brzozowski()`, `complement()`, `reverse()` возвращают новый автомат. `complete()` при необходимости сначала строит ДКА. Дополнение берётся относительно `alphabet`; `reverse()` обращает слова языка.
- `is_deterministic()` и `is_complete()` проверяют свойства автомата; `copy()` создаёт независимую копию.
- `to_dot()` возвращает описание графа; `draw('graph.dot')` сохраняет DOT-файл. Для PNG, SVG и PDF нужна установленная программа Graphviz (`dot`).
